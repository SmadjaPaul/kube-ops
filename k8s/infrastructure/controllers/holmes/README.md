# HolmesGPT SRE engine

HolmesGPT is the event-driven RCA engine for the homelab. It is not a
Kubernetes remediation plane.

## Design

- Holmes 0.42.0.
- Uses the existing in-cluster LiteLLM proxy.
- Fast/default model: `azure/gpt-5-mini`.
- Deep investigation model: `azure/gpt-5.4`.
- Reads Kubernetes status/logs, Prometheus and Loki.
- No Bash toolset.
- No Kubernetes remediation MCP.
- No public Gateway/HTTPRoute.
- Holmes HTTP API requires `HOLMES_API_KEY` when activated.
- Kubernetes RBAC is read-only and deliberately excludes Secret objects.

## Activation gate

This chart is initially rendered with `replicas: 0`.

After `HOLMES_API_KEY` is generated by homelab-infra and applied to
Doppler `cluster/prd`:

1. Render `externalsecret.yaml` in this directory.
2. Change `replicas` to 1.
3. Verify the Holmes API health endpoint.
4. Verify a read-only investigation through LiteLLM, Prometheus and Loki.
5. Only then enable the Holmes Operator / event triggers in a separate PR.

The operator and GitHub remediation path are intentionally not part of this
bootstrap PR.
