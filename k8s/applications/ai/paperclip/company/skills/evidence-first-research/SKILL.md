# Evidence-first research

Prefer the actual repository, upstream documentation, release notes, security advisories and source code. Record the date/version for fast-moving systems. Distinguish confirmed behavior from inference and community opinion.

Return only what the parent task needs: findings, evidence, recommended design implications, uncertainty and any required follow-up test. Never convert a research conclusion into an unreviewed production mutation.
